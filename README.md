## Variables requises :
Salle :
* Nom
* Capacité max (en personne)
Réservation :
* Date début réu
* Date fin réu
* Nb personne à la réunion

# Aide 

Installer Jest :
```Bash
npm install --save-dev jest
```

Lancer les tests : 
```Bash
npx jest
```

Lancer la bdd :
```Bash
npx json-server backend/db.json
```
