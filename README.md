# CS2I_TDD_RSR
CS2I - TP de TDD : Système de Réservation de Salles de Réunion

## Variables requises :
Salle :
* Nom
* Capacité max (en personne)
* Date début réu
* Date fin réu
* Nb personne à la réunion

# Aide 

Installer Jest :
```Bash
npm install --save-dev jest
```

Lancer les tests : 
```Bash
npx jest
```
